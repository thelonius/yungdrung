Причины переноса

Список для окна контроля. Архивная причина не пропадает из истории, но больше не предлагается при выборе новой.

    Отклонённые совпадения базы знаний

    Кнопка «нет» на предложенной ссылке и «заглушить слово» пишутся сюда навсегда — без отмены случайный клик снимает слово с распознавания на всю базу. «Слово целиком» — отказ у любой записи, «запись» — только у неё.

      Отказов пока нет.

      Теги

      Справочник тегов, которые реально стоят на задачах. Цвет и закрепление видны на карточках; «Объединить» переносит все задачи с исходного тега на целевой и убирает исходный из справочника.

        Резервные копии

        Копия — весь вольт одним файлом, для восстановления после сбоя. Хранится отдельно от вольта, чтобы пропажа папки её не задела.

          Копий пока нет. Первая появится по кнопке выше.

          Экспорт

          Вся база одним JSON-файлом — без нашего формата хранения, чтобы будущая версия продукта прочитала данные, не заставляя заводить всё заново.
